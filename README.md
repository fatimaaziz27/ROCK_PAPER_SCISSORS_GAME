# ROCK PAPER SCISSORS GAME

A simple and interactive **Rock, Paper, Scissors** game built using **HTML, CSS, and JavaScript**.

This project is designed to practice **DOM manipulation** and JavaScript fundamentals by creating an interactive browser-based game.

## About

The game allows the player to choose between:

* Rock
* Paper
* Scissors

The computer randomly selects one of the three choices, and JavaScript determines the winner.

The game dynamically updates the webpage based on the player's choice and the game result.

## How It Works

### 1. Player Choice

The player selects **Rock**, **Paper**, or **Scissors** by clicking a button.

### 2. Computer Choice

JavaScript randomly selects one of the three choices for the computer.

### 3. Determine the Winner

The game compares both choices:

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Same choices result in a draw

### 4. Update the Page

JavaScript updates the game result and scores using DOM manipulation.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Choose Rock, Paper, or Scissors.
5. Play the game.

No additional installation is required.
