

# ROCK PAPER SCISSORS GAME

An interactive Rock, Paper, Scissors game built using **HTML, CSS, and JavaScript** to practice DOM manipulation and core JavaScript concepts.

## About

This project is based on the classic Rock, Paper, Scissors game and focuses on making a webpage interactive using JavaScript.

Players select Rock, Paper, or Scissors, and the computer makes its own choice. The game compares both choices, determines the result, and updates the scores dynamically.

## Features

- Rock, Paper, and Scissors selection
- Random computer choice
- Automatic winner determination
- Player score tracking
- Computer score tracking
- Round result messages
- Dynamic webpage updates
- Reset game functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Practiced

- DOM manipulation
- `getElementById()`
- `querySelector()`
- Event handling
- Functions
- Variables and constants
- Conditional statements
- Random number generation
- Updating text content
- Click events

## Game Rules

- **Rock beats Scissors**
- **Scissors beats Paper**
- **Paper beats Rock**
- If both choices are the same, the round is a draw.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Select Rock, Paper, or Scissors to play.
5. Use the reset button to start a new game.

No additional installation is required.

## Learning Objectives

This project helps practice:

- Connecting JavaScript with HTML elements
- Handling button clicks
- Updating webpage content dynamically
- Implementing game logic
- Managing scores with JavaScript
- Creating interactive web applications

## Purpose

The purpose of this project is to strengthen JavaScript skills by building a simple game while learning how DOM manipulation connects user actions with webpage updates.
